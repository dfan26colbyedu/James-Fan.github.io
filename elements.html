2022


AI Image Denoiser

To address the problem that low sample path tracing gives noisy results, an AI-based image denoiser that can reduce noise in low-sample renders while maintaining a balance between output quality and computational efficiency is developed. The model was trained using high-sample, noise-free images paired with corresponding noisy, low-sample versions to learn how to reconstruct clean images. The training process utilized a combination of pixel-wise and perceptual losses to ensure that the output is both accurate and visually appealing. The modal is compared with an anisotropic diffusion based denoiser and a Bilateral filter denoiser and showed generally better results.

Symbolic Physics Calculator

A new project I am working on that integrates symbolic math calculation, equation solver with a free canvas environment that allows user to explore the physics behind equations and document their thought processes. The app aims to provide an easy to user interface that requires no knowledge for coding or formal languages from the users. The app will be build using Flask and libraries like SymPy and SageMath.
